The problem

A small feed-forward neural network has two inputs (x₁, x₂), two hidden neurons (H₃, H₄) with ReLU activation, and one output neuron (O₅) with no activation, because this is regression. There are no bias terms. The network is trained on a single sample (x₁, x₂) whose true value is y, using the squared-error loss Loss = (ŷ − y)² and gradient descent with learning rate lr.

How to read the weight names: Wᵢₖ is the weight on the arrow going from neuron i to neuron k. The inputs are neurons 1 and 2, the hidden neurons are 3 and 4, and the output is neuron 5. So W₂₄ is "input 2 → hidden 4", and W₄₅ is "hidden 4 → output".

The 14 questions below take the network through one complete training iteration: 1–3 Forward pass 4 Loss 5–12 Backpropagation 13–14 Weight update. Work each one out yourself, then click Reveal to check. Change any value below and click Start to work the same questions with your own numbers.

Side note — Batch, Mini-Batch or Stochastic GD?
This simulator trains on one sample, so all three variants are the same here. With N samples, backprop runs once per sample exactly as shown, the gradients are averaged over the batch, and only then is the weight update applied. The variants differ only in how many samples go into one update.
Training log
What this model simplifies
One training sample, no bias terms, ReLU hidden neurons, a linear output and squared-error loss. ReLU′(0) is taken as 0, as PyTorch does. Values are computed at full precision and shown to 4 decimal places, so multiplying the rounded factors by hand can differ in the last digit. Updated weights are rounded to 4 decimals, as you would do by hand, so every iteration can be checked with a calculator. Biases, when present, get gradients by the same chain rule.

Update rules used in this part
⚡ Key insight
Momentum and Adam remember the direction of past gradients (v, m), so they can keep moving against the current gradient. AdaGrad and RMSprop remember only the size of past gradients (gradient²), so they can make the step bigger or smaller but never reverse it: like plain GD, they always follow the current gradient.
Figure 5 — The five optimizers on the 2-2-1 network
What this part simplifies
The formulas are the moving-average forms shown above: momentum v = 0.9v + 0.1g (PyTorch uses v = 0.9v + g), RMSprop 0.99 / 0.01, Adam 0.9 / 0.999, and ε inside the square root. Real Adam also applies bias correction, m̂ = m/(1 − 0.9ᵗ) and v̂ = v/(1 − 0.999ᵗ); it is skipped here to keep the arithmetic short. PyTorch adds ε outside the root.
